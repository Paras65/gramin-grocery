# Render.com Deployment Guide — Gramin Kirana POS

Gramin Kirana is configured for **1-Click Unified Full-Stack Deployment** on Render (Frontend + Backend on a single free Web Service).

---

## 🚀 1-Click Blueprint Setup (Recommended)

1. **Sign in to Render**: Go to [https://dashboard.render.com](https://dashboard.render.com).
2. Click **New +** → Select **Blueprint**.
3. Connect your GitHub repository:
   ```
   https://github.com/Paras65/gramin-grocery.git
   ```
4. Render will automatically detect `render.yaml` and configure:
   - **Service Name:** `gramin-kirana-pos`
   - **Environment:** `Node`
   - **Build Command:** `npm install && npm run build:all`
   - **Start Command:** `npm start`
   - **Health Check Path:** `/health`
5. **Set Environment Variables**:
   Render will ask you for `MONGODB_URI`:
   - Enter your MongoDB Atlas connection string:
     ```
     mongodb+srv://<username>:<password>@cluster0.qrqi6.mongodb.net/gramin_kirana?retryWrites=true&w=majority
     ```
   - `JWT_SECRET` will be automatically generated by Render.
6. Click **Apply**.
7. Render will build both client and server and launch your live POS app!

---

## ⚠️ Critical Step: MongoDB Atlas IP Access List

Render uses dynamic IP addresses on its free tier. Ensure MongoDB Atlas accepts connections from Render:

1. Open [MongoDB Atlas Dashboard](https://cloud.mongodb.com/).
2. In the left sidebar, click **Network Access**.
3. Click **Add IP Address**.
4. Select **Allow Access From Anywhere** (`0.0.0.0/0`).
5. Click **Confirm**.

---

## 🛠️ Manual Web Service Setup (Alternative)

If you prefer setting up manually without Blueprints:

| Setting | Value |
|---|---|
| **Type** | Web Service |
| **Name** | `gramin-kirana-pos` |
| **Language** | `Node` |
| **Branch** | `main` |
| **Build Command** | `npm install && npm run build:all` |
| **Start Command** | `npm start` |
| **Health Check Path** | `/health` |

### Environment Variables:
- `NODE_ENV`: `production`
- `PORT`: `10000`
- `MONGODB_URI`: `your_mongodb_atlas_connection_string`
- `JWT_SECRET`: `your_random_secret_string`
- `RATE_LIMIT_MAX`: `300`
